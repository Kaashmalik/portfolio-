04 Adding live links

The exact click paths. This is the part most people get wrong.

LinkedIn only makes links clickable in specific places. A URL typed into your About section is plain text — it looks like a link, but nobody can tap it. So the strategy is: put your proof where LinkedIn allows clicking, and stop relying on the places it does not.

WhereClickable?Use it for
Featured sectionYesAll 7 projects, with thumbnails
Contact info → WebsiteYesPortfolio, company site, GitHub
Custom profile buttonYes"Visit portfolio" next to Connect
Posts, comments, articlesYesBuild logs and case studies
About section textNoLeave URL for copy-paste only
Experience descriptionsNoDescribe the outcome, not the link
HeadlineNoMessage only — no URLs

4.1 · Add the seven Featured links

  1. Open your profile and scroll to the Featured section.
  2. Click the + (or the pencil, then +). A menu appears.
  3. Choose Add a link.
  4. Paste the URL from the table on the next page. LinkedIn fetches a preview.
  5. Replace the auto-generated title with the custom title from the table — this is what people read.
  6. Click Add media → upload the matching PNG from your linkedin-assets folder.
  7. Save. Repeat for each project, strongest first — Featured displays in the order you add them.
Why thumbnails matter A Featured card with a real screenshot gets scanned as proof. A bare URL card gets ignored as spam. All four images are already cropped to 1200 × 630 and named in the order to upload them.

4.2 · Set the custom button

  1. Open your profile and click the pencil / Edit profile.
  2. Find the custom button area near the top, beside Connect and Message.
  3. Choose the label Visit portfolio (or Visit website if that option appears instead).
  4. Paste https://pf.mtkcodex.site and save.

4.3 · Add links to Contact info

  1. On your profile, open Contact info (under the intro, or via More).
  2. Click the pencil and choose Website → Add website.
  3. Set the label to Portfolio and the URL to https://pf.mtkcodex.site.
  4. Add a second entry labelled GitHub → https://github.com/Kaashmalik.
  5. Confirm your email and phone (WhatsApp) are present, then save.

4.4 · If a link will not attach

  • No preview appears — your site is blocking LinkedIn's crawler. Add the link anyway, then upload the thumbnail manually.
  • "URL not valid" — missing https://, a trailing space, or a local file path. Paste the exact URL from page 5.
  • Wrong image on the card — LinkedIn cached the page's default social image. Remove the item, re-add it, upload media instead.
  • Cannot feature someone else's post — by design. Only your own posts, articles and links can be featured.
  • Cards appear out of order — Featured follows the order you added them. Remove and re-add to reorder.

06 Recommendations & content

Trust, then proof. This is what turns a profile into inbound work.

Request three recommendations this week

You currently show none. For freelance and contract hiring this is the single highest-leverage fix on the page. Send this to the InstalEase owner, the Shakir Super League organiser, and the MTK Edu administrator:

Message templateHi [Name] — I'm updating my LinkedIn with the work we shipped together and I'd be grateful for a short recommendation. If it helps, here's a draft you can edit: "Kashif built our [platform] end to end — [one specific thing he solved]. He shipped on schedule, communicated clearly, and the system has run reliably since launch. I'd hire him again." No pressure if you're busy — even two sentences helps. Thank you!

Then recommend them back. Reciprocity roughly doubles the response rate. Ask the same three for a two-line testimonial with name, role, company and LinkedIn URL for the portfolio — anonymous quotes are worth very little.

A four-post rotation that generates inbound

Post one to two times a week. Proof beats motivation every time.

SlotFormatHook
Build log What shipped + the hard part "Shipped this week: [feature]. The hard part was not the UI — it was [problem]."
Teardown One technical lesson "Most multi-tenant SaaS apps leak data in one place: [place]. Here's the checklist."
Client outcome Before → after, with a number "[Client] ran [process] in spreadsheets. Now [number] farms use it daily."
Soft CTA Availability + process "I have room for one more build this month. Here's how I scope it: 1… 2… 3…"
Posting mechanics Only the first two lines show before see more — make them the hook. Keep external links out of the post body (LinkedIn suppresses reach); put them in the first comment. Reply to every comment within the first hour.
