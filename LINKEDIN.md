## 7A. How to actually add the live links (click-by-click)

> A printable version of this section is at `public/documents/LinkedIn-Playbook.pdf`.
> Ready-to-upload thumbnails are in `linkedin-assets/`.

### Where LinkedIn lets you click

| Where | Clickable | Use it for |
|---|---|---|
| Featured section | **Yes** | All 7 projects, with thumbnails |
| Contact info → Website | **Yes** | Portfolio, company site, GitHub |
| Custom profile button | **Yes** | "Visit portfolio" next to Connect |
| Posts, comments, articles | **Yes** | Build logs and case studies |
| About section text | **No** | Leave the URL for copy-paste only |
| Experience descriptions | **No** | Describe the outcome, not the link |
| Headline | **No** | Text only — no URLs |

A URL in your About section looks like a link but nobody can tap it. Put your proof in the three
clickable places and stop relying on the rest.

### Step 1 — Add the seven Featured links

1. Open your profile → scroll to **Featured**
2. Click **+** (or the pencil, then **+**)
3. Choose **Add a link**
4. Paste the URL from the table below
5. Replace the auto-generated title with the custom title (that is what people read)
6. Click **Add media** → upload the matching PNG from `linkedin-assets/`
7. Save, then repeat — **strongest first**, because Featured displays in the order you add

### Step 2 — Set the custom button

1. Profile → pencil / **Edit profile**
2. Find the **custom button** area near the top, beside Connect and Message
3. Choose **Visit portfolio** (or **Visit website** if that is the option offered)
4. Paste `https://pf.mtkcodex.site` and save

### Step 3 — Add links to Contact info

1. Profile → **Contact info** (under the intro, or via **More**)
2. Pencil → **Website** → **Add website**
3. Label `Portfolio`, URL `https://pf.mtkcodex.site`
4. Add a second entry: label `GitHub`, URL `https://github.com/Kaashmalik`
5. Confirm email and phone, then save

### If a link will not attach

- **No preview appears** — your site is blocking LinkedIn's crawler. Add the link anyway, upload the thumbnail manually.
- **"URL not valid"** — missing `https://`, a trailing space, or a local file path. Paste the exact URL.
- **Wrong image on the card** — LinkedIn cached your page's default social image. Remove, re-add, upload media instead.
- **Cannot feature someone else's post** — by design. Only your own posts, articles and links.
- **Cards out of order** — Featured follows the order you added them. Remove and re-add to reorder.

**Friday — proof / client outcome**
```
[Client] was managing [process] in spreadsheets.

We replaced it with [system]. [Number] farms/shops/schools now use it daily.

Screenshot below. Happy to walk through the architecture.
```

**Weekly — hiring CTA (soft)**
```
I have room for one more build this month.

If you are turning a manual process into a SaaS product, here is how I scope it:
1. 30-min discovery
2. Written fixed-scope proposal
3. Weekly demos
4. Handover with docs and credentials

Portfolio in the comments.
```

**Posting rules:** first 2 lines are the hook (only those show before "see more"), no external links in
the body (put them in the first comment), and reply to every comment in the first hour.
